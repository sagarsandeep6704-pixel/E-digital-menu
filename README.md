# E-digital-menu
Main aapke menu se ek ordering page bana raha hoon jo order seedha WhatsApp par bhejega.

Aapka WhatsApp ordering page ban gaya hai. Isme menu ke saare items category ke hisaab se hain, Add/+/− se quantity badhti hai, aur Delivery ya Pickup chun sakte hain. Customer naam, phone aur pata bharke "WhatsApp par order bhejein" dabata hai, to poora order 9166004130 par ready message ke roop mein khulta hai.

Ek zaroori baat: page abhi sirf aapko dikhega. Customers ko bhejne ke liye page ke Share menu se link share karna hoga.

Menu ki photo mein kuch prices watermark ke peeche dhundhle the (jaise Chicken Kasha 228, Chicken Bharta 259, Chicken Butter Masala 270). Tandoori Chicken Full aur Half dono 175 dikh rahe the. Ek baar prices check kar lein, aur galat ho to bata dein, main theek kar dunga.
